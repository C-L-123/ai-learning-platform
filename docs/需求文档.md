# AI智能学习平台需求文档

## 1. 项目概述

### 1.1 项目背景
本项目是将两个独立的AI学习系统进行完整合并，打造一个统一的智能学习平台。通过整合AI学情分析和智能刷题两大核心功能，形成"分析-刷题-再分析"的完整学习闭环，为用户提供一站式的智能学习解决方案。

### 1.2 项目目标
- 统一用户认证体系，实现单点登录
- 整合两个系统的数据库设计
- 实现功能数据互通，形成学习闭环
- 提供统一的用户界面和交互体验
- 确保系统100%可运行，功能完整

## 2. 系统架构

### 2.1 技术架构
```
┌─────────────────────────────────────────┐
│              前端层 (Vue3)               │
│  Element Plus + ECharts + Pinia + Axios │
└───────────────────┬─────────────────────┘
                    │
┌───────────────────▼─────────────────────┐
│              后端层 (Flask)              │
│  JWT认证 + PaddleOCR + SQLAlchemy       │
└───────────────────┬─────────────────────┘
                    │
┌───────────────────▼─────────────────────┐
│              数据层 (MySQL)              │
│  用户 + 题库 + 学习记录 + 分析结果       │
└─────────────────────────────────────────┘
```

### 2.2 模块划分
1. **用户认证模块** - 注册、登录、JWT认证
2. **学情分析模块** - OCR识别、知识点提取、掌握度分析
3. **智能刷题模块** - 题目推荐、在线答题、自动判分
4. **错题本模块** - 错题收录、复习管理、掌握标记
5. **数据看板模块** - 学习数据可视化、趋势分析

## 3. 功能需求详细说明

### 3.1 用户认证系统

#### 3.1.1 用户注册
- 输入：用户名、邮箱、密码、确认密码
- 验证：用户名唯一性、邮箱格式、密码强度
- 输出：注册成功/失败提示

#### 3.1.2 用户登录
- 输入：用户名、密码
- 验证：用户存在性、密码正确性
- 输出：JWT Token + 用户信息
- 会话管理：Token有效期7天

#### 3.1.3 个人中心
- 用户信息展示与修改
- 密码修改功能
- 学习数据总览

### 3.2 AI学情分析模块

#### 3.2.1 试卷上传与OCR识别
- 支持图片格式：jpg、png、bmp、gif
- 文件大小限制：16MB
- OCR引擎：PaddleOCR（中文识别）
- 支持批量上传

#### 3.2.2 知识点提取
- 自动识别试卷中的知识点关键词
- 按科目分类（数学、英语、物理、化学）
- 支持自定义知识点

#### 3.2.3 掌握度分析
- 知识点掌握度雷达图展示
- 薄弱知识点自动标记（掌握度<70%）
- 生成个性化学习建议

#### 3.2.4 历史记录管理
- 分析历史列表展示
- 分析详情查看
- 支持删除历史记录

### 3.3 智能刷题模块

#### 3.3.1 刷题模式
1. **智能推荐模式**
   - 基于用户薄弱知识点推荐题目
   - 优先推荐掌握度低的知识点题目

2. **自定义选题模式**
   - 按科目筛选题目
   - 按知识点筛选题目
   - 选择题量（5-50题）

#### 3.3.2 在线答题
- 题目展示：题干+选项（单选/多选/填空）
- 实时答题计时
- 答案提交与验证

#### 3.3.3 自动判分
- 答案正确性即时判断
- 正确答案与解析展示
- 自动更新知识点掌握度

#### 3.3.4 统计功能
- 累计刷题数统计
- 总体正确率计算
- 每日刷题趋势
- 学习时长统计

### 3.4 错题本模块

#### 3.4.1 错题自动收录
- 答错题目自动加入错题本
- 记录错误答案和错误次数
- 自动关联对应知识点

#### 3.4.2 错题分类管理
- **待复习**：需要重点复习的错题
- **已掌握**：已熟练掌握的错题
- 支持手动切换状态

#### 3.4.3 错题复习
- 错题重做功能
- 复习结果提交
- 连续答对自动标记为掌握

#### 3.4.4 复习提醒
- 今日待复习错题提示
- 按错误次数优先级排序
- 复习进度追踪

### 3.5 首页数据看板

#### 3.5.1 核心指标卡片
- 累计刷题总数
- 总体正确率百分比
- 累计学习时长（分钟）
- 待复习错题数量

#### 3.5.2 数据可视化
- 每日刷题量柱状图
- 正确率趋势折线图
- 薄弱知识点TOP5排行

#### 3.5.3 快捷入口
- 上传试卷分析
- 开始智能刷题
- 复习错题

## 4. 数据互通与闭环设计

### 4.1 数据流设计

```
学情分析 → 识别薄弱点 → 智能推题 → 用户刷题
    ↑                                         ↓
    └──────── 更新掌握度 ←─ 答题结果 ─────────┘
```

### 4.2 数据更新规则
1. **刷题影响掌握度**
   - 答对：知识点掌握度 +5%
   - 答错：知识点掌握度 -10%
   - 掌握度范围：0-100%

2. **错题关联机制**
   - 每道错题自动关联对应知识点
   - 错误次数影响该知识点掌握度计算

3. **智能推题算法**
   - 掌握度越低，推荐题目越多
   - 每个薄弱点优先推荐2-3题
   - 题目难度循序渐进

## 5. 数据库设计

### 5.1 核心数据表

#### users（用户表）
- id, username, email, password, nickname, avatar, created_at

#### questions（题目表）
- id, subject, knowledge_point, difficulty, question_type
- content, options, answer, analysis, created_at

#### study_records（学习记录表）
- id, user_id, question_id, study_type, is_correct
- answer_time, study_date, created_at

#### exam_papers（试卷表）
- id, user_id, title, subject, image_path, ocr_content
- analysis_result, knowledge_points, mastery_level, created_at

#### wrong_questions（错题本表）
- id, user_id, question_id, wrong_answer, wrong_count
- status, last_review_at, created_at

#### user_knowledge_mastery（知识点掌握度表）
- id, user_id, knowledge_point, subject
- total_questions, correct_questions, mastery_rate
